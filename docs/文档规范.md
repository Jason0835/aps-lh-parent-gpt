# 文档编写规范

## 标题规范
- 一级标题（#）作为文档总标题，每个文档仅一个。
- 二级标题（##）作为主章节标题，带序号，如 `## 步骤1：xxx`、`## 步骤2：xxx`。
- 三级标题作为子章节标题，**不要加序号**，**不用 `###` 标记**，用列表嵌套形式表示，即作为上级二级标题列表项下的子列表项。
- 四级及以下标题同理，继续用列表嵌套，不再使用 `####` 标记。

## 表格规范
- 表格**不要缩进**，顶格书写，即表格的 `|` 符号从行首开始，前后不要有空格或缩进。
- 表格前后各保留一个空行，与上下内容分隔。
- 表头与表体之间使用分隔行（`|---|---|`），分隔行的宽度与表头列数一致。

## 内容规范
- 使用中文编写文档。
- 代码块使用三个反引号（```）包裹，并标注语言类型（如 `java`、`sql` 等）。
- 文件引用使用相对路径或绝对路径，路径中注意转义。
