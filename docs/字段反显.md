# 字段反显规则

有些字段不是当前表直接存储的字段，需要根据当前记录中的编码字段，从关联表中反显名称或描述。例如 `materialDesc` 需要根据 `materialCode` 从 `T_MDM_MATERIAL_INFO` 反显 `MATERIAL_DESC`。

## 实体字段

反显字段如果不在当前数据库表中，实体字段必须添加 `@TableField(exist = false)`。

如果反显字段需要导出 Excel，必须同时添加 `@Excel`，并且 `name` 使用多语言 key。

示例：

```java
@ApiModelProperty(value = "物料描述")
@TableField(exist = false)
@Excel(name = "ui.data.column.lhRepairCapsule.materialDesc")
private String materialDesc;
```

## 反显公式

反显公式统一写在 ServiceImpl 的 `getQueryFormulas()` 中，并在 Service 接口中声明该方法，Controller 中只委托 Service 获取公式。

示例：

```java
@Override
public String[] getQueryFormulas() {
    return new String[]{
            "materialDesc -> getcolvalue(T_MDM_MATERIAL_INFO, MATERIAL_DESC, MATERIAL_CODE, materialCode)"
    };
}
```

Controller 示例：

```java
@Override
protected String[] getQueryFormulas() {
    return lhRepairCapsuleService.getQueryFormulas();
}
```

## 导出反显

如果 Controller 使用框架默认导出逻辑，框架会读取 `getQueryFormulas()` 处理反显。

如果 Controller 重写了 `listExportData()`，并且直接调用 mapper 查询导出数据，则必须在返回前调用：

```java
AppUtils.formatData(list, getQueryFormulas());
```

示例：

```java
@Override
protected List<LhRepairCapsule> listExportData(LhRepairCapsule obj) {
    QueryWrapper<LhRepairCapsule> wrapper = new QueryWrapper<>();
    this.builderCondition(wrapper, obj);
    List<LhRepairCapsule> list = lhRepairCapsuleMapper.selectList(wrapper);
    AppUtils.formatData(list, getQueryFormulas());
    return list;
}
```

## 反显字段查询

如果需要按反显字段查询，不能直接使用反显字段作为当前表字段查询。应在 `builderCondition()` 中使用 `EXISTS` 关联反显来源表，并使用 `{0}` 参数占位传值，不要手动拼接查询值。

示例：

```java
queryWrapper.apply(PubUtil.isNotEmpty(queryVO.getFieldValueByFieldName("materialDesc")),
        "EXISTS (SELECT 1 FROM T_MDM_MATERIAL_INFO m WHERE m.MATERIAL_CODE = t_lh_repair_capsule.MATERIAL_CODE AND m.MATERIAL_DESC LIKE CONCAT('%',{0},'%'))",
        queryVO.getFieldValueByFieldName("materialDesc"));
```

## 注意事项

- 不要为了反显字段在 Controller 中手写额外查询，优先使用 `getQueryFormulas()`。
- 反显字段作为查询条件时，优先使用 `EXISTS`，不要使用 `IN (SELECT ...)`。
- `EXISTS` 子查询中引用主表字段时，必须显式加主表表名或别名，例如 `t_lh_repair_capsule.MATERIAL_CODE`，避免字段歧义。
- 不要在实体中重复定义 `BaseEntity` 已经有的字段，例如 `id, createBy, createTime, updateBy, updateTime, isDelete, remark`。
- 需要按额外条件反显时，使用 `getcolvaluewithcondition(...)`。
- 多个反显字段时，在 `getQueryFormulas()` 返回数组中逐条添加。
