## 1. 概述

垫胶工序是轮胎生产过程中将胶料通过挤出机挤出成型为特定断面形状垫胶的生产工序。垫胶成型后需经台车卷曲收纳并停放冷却 3 小时后，方能送往成型工序使用。

本文档梳理了垫胶工序所有业务功能的前端页面设计、后端接口设计及对应的数据库设计。

## 13. 垫胶备库班数与供成型机数配置

### 13.1 功能说明

该功能用于配置垫胶排产深度规则，根据成型工序生产某规格所使用的成型机台数量范围，确定对应的垫胶备库班数（即垫胶需提前备库多少个班的产量）。排程算法根据该配置计算不同规格垫胶的供应窗口大小。

排产深度决定了垫胶需覆盖的成型班次数。成型机台数越少，单机台产量负荷越大，该垫胶需覆盖更多成型班次；成型机台数越多，总产能越大，覆盖较少班次即可满足。

**对应算法规则**：算法设计文档步骤 3.2 中根据成型机台数量匹配 `T_DJ_DEPTH_CONFIG` 配置表获取排产深度的逻辑，由该配置表统一管理。

**字段说明**：
- **供成型机台数（MACHINE_QTY）**：消耗该垫胶的成型机台去重后的数量，为匹配基准值。
- **机台范围（MACHINE_RANGE）**：与 MACHINE_QTY 组合构成匹配条件。例如 MACHINE_QTY=3、MACHINE_RANGE=大于等于，表示匹配条件为"供成型机台数 ≥ 3"。
- **垫胶备库班数（DEPTH_CLASS_QTY）**：匹配成功后，垫胶需覆盖的成型班次数（即供应窗口大小）。垫胶下计划班次数 = 备库班数 + 1（提前一个班）。

**业务唯一约束**：`FACTORY_CODE` + `MACHINE_QTY` + `MACHINE_RANGE`（同一工厂下同台数同范围条件只能有一条配置）

**数据完整性约束**：`MACHINE_RANGE` + `MACHINE_QTY` 组合不允许有交叉（除非备库班数 `DEPTH_CLASS_QTY` 相同）。例如配置了两条规则「MACHINE_QTY ≥ 3」备库班数=4 和「MACHINE_QTY ≤ 5」备库班数=6，当实际台数为 4 时两条规则均匹配且备库班数不同，即构成交叉。若两条规则的备库班数相同（如均为4），则允许范围重叠。新增或修改配置时必须校验是否存在与现有规则产生交叉且备库班数不同的情况。

**匹配规则**：排程算法按 MACHINE_QTY 降序匹配，取第一个满足条件的配置行对应的 DEPTH_CLASS_QTY 值。

**数据字典**：`machine_range`（该字典供各工序通用，不限于垫胶，含中文/越南语）

| 字典值 | 中文标签 | 越南语标签 |
|--------|---------|-----------|
| LT | 小于 | Nhỏ hơn |
| LE | 小于等于 | Nhỏ hơn hoặc bằng |
| EQ | 等于 | Bằng |
| GE | 大于等于 | Lớn hơn hoặc bằng |
| GT | 大于 | Lớn hơn |
