## 四、关键逻辑要点

### 1. 优先级排序（sortByPriority）

需实现 `Comparator<DjPaddingDemand>`，按9级规则逐级比较：

| 级 | 规则 | 判定条件 |
|:--:|:---|:---------|
| 1 | 本班库存有缺口优先 | `needProduce == true` 优先 |
| 2 | 规格续作优先 | paddingCode 与上一班最后规格相同 |
| 3 | 胶料相同 + 口型相同 | glueCode + mouthPlateCode 均相同 |
| 4 | 胶料相同 | glueCode 相同 |
| 5 | 口型相同 | mouthPlateCode 相同 |
| 6 | 胶料组相同 | glueGroupCode 相同 |
| 7 | 胶料序号升序 | glueSeq 升序 |
| 8 | 库消比升序 | `incomingInventory / avgDailyConsume` 升序 |
| 9 | 垫胶编码升序 | paddingCode 字典序 |

### 2. 生产量计算（calcProduceQty）

```
已收尾规格：
    produceQty = min(remainingDemand, remainingCapacity)

未收尾规格：
    // 台车整倍数约束
    maxTrolleys = floor(remainingCapacity / trolleyCapacity)
    needTrolleys = ceil(remainingDemand / trolleyCapacity)
    actualTrolleys = min(maxTrolleys, needTrolleys)
    若 actualTrolleys <= 0 → produceQty = 0（跳过）
    否则 produceQty = actualTrolleys × trolleyCapacity
    // 若剩余需求不足一台车，至少生产一台车
    若 remainingDemand > 0 且 remainingCapacity >= trolleyCapacity:
        produceQty = trolleyCapacity
```

### 3. 切换损失（calcSwitchLoss）

```
本班第一个规格 或 续做同一规格 → switchLoss = 0
同胶料 + 同口型（同一规格续做）→ switchLoss = 0
同胶料 + 不同口型（仅换口型）→ switchLoss = (MOUTH_PLATE_SWITCH_TIME / 8) × quata
不同胶料（胶料+口型都换）   → switchLoss = (GLUE_SWITCH_TIME / 8) × quata
```

### 4. 台车总容量约束

```
班次总产量上限 = (工装总数 - (有效库存 / 卷曲米数) × 整车率) × 台车容量
```

在每班排产完成后校验，若总排产量超过上限则依次削减最后安排的规格产量。

### 5. 批次号生成

```
batchNo = "DJ" + yyyyMMdd + 3位序号
  - 3位序号：查询 T_DJ_SCHEDULE_RESULT_LOG 表当天最大 batchNo 的序号 +1
  - 当天无记录则从 001 开始

orderNo = batchNo + 4位序号
  - 每个 batchNo 批次内从 001 开始连续编号
```

### 6. 历史归档流程

```
1. 查询 T_DJ_SCHEDULE_RESULT 中 factoryCode + scheduleDate 的旧记录
2. 若存在，批量插入 T_DJ_SCHEDULE_RESULT_LOG
3. 删除 T_DJ_SCHEDULE_RESULT 中的旧记录
4. 批量插入新的排产结果到 T_DJ_SCHEDULE_RESULT
```
