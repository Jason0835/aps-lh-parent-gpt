# 前端开发规范

## 一、通用规范

### 1.1 下拉选择框
- **所有下拉选择框必须添加 `filterable` 属性**支持可输入筛选

### 1.2 factoryCode 字段处理
- **字典反显方式：** 使用 `selectDictLabel(this.dict.type.biz_factory_name, value)`
- **列表位置：** factoryCode 在列表中必须放在第一列

### 1.3 冗余字段
- `companyCode` 冗余字段不在任何界面显示

### 1.4 多语言规范
- **多语言key格式：** `ui.data.column.cxEntityName.fieldName`

---

## 二、列表字段样式规则

### 2.1 描述类字段（xxxDesc）
**适用字段：** `materialDesc`, `productDesc`, `specDesc`, `mainMaterialDesc`, `embryoDesc`, `beforeMaterialDesc`, `afterMaterialDesc`, `beforeSpecDesc`, `afterSpecDesc`, `disableMaterialDesc`, `fixedMaterialDesc` 等

**配置规则：**
```javascript
{
  prop: "xxxDesc",
  align: "left",
  minWidth: 350
}
```
- **align:** `"left"` 左对齐
- **minWidth:** `350` 最小宽度350

---

## 三、字段样式修改注意事项

1. **只修改 `computed: { columns() {` 中的列：** 以上样式规则仅适用于 `computed` 计算属性中 `columns()` 函数内的表格列配置，其他位置的列（如 `searchColumns`、`importColumns`、模板内联的 `:columns` 等）不应用此样式规则
2. **只应用于列表列：** 以上规则仅适用于表格列表展示列，不适用于表单字段（有 `type:`, `render:`, `dictData:` 等属性的字段）
3. **已注释的代码不修改：** 如果字段配置已被注释（`//` 开头），则不进行修改
4. **已有属性的处理：** 如果字段已有 `align` 或 `minWidth` 属性，则修改其值，不存在的属性则添加

## 四、文件范围

以上规则适用于所有 `index.vue` 文件中 `computed: { columns() {` 计算属性内的表格列配置。
